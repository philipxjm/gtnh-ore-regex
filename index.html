How to use

  1. Pick the common logic — the processing route ordinary ores take. Ores in the special list follow their own route instead.
  2. Paste each machine's regex into the filter feeding that machine: a GregTech Ore Dictionary Filter cover, or an ME storage bus / interface with an oredict filter. The 1024-character counter matches the filter cover's limit.
  3. Hover a route to see its chain. Item forms flow ore → crushed → purified / centrifuged → impure / purified dust → dust; every regex targets the oredict names of exactly those intermediate forms.
